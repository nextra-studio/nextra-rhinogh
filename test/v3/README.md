# v3: all cases on three systems

Every v1 case (01–10, 12–16) plus new cases 17–20, run on Nextra, McNeel Rhino-MCP-Platform and RhinoMCP.
Input and output tokens are counted separately, and each result is checked neutrally. **Read [REPORT.md](REPORT.md).**

| file | what |
|---|---|
| `REPORT.md` | results, method, what makes the difference, findings, caveats |
| `tables_v3.md` | full tables, generated by `gen_report3.py` from `rows_v3.json` |
| `rows_v3.json` | every call (system, case, task, tool, output tokens, input tokens), fixed context, checks |
| `out/<case>/<system>/NN_task_tool.txt` | every request and reply exactly as exchanged |
| `bench_v3.py` | the harness: one function per case, all three systems, neutral checks |
| `specs3.py` | neutral Grasshopper specs (tower, fins, Karamba beam, house FE, trees, Karamba shell) and per-system emitters |
| `pyhelpers.py` | the Python the other systems must send for things they have no native tool for (counted) |
| `scripts/` | canopy, big model and frame scripts; data-tree, shell and messy-canvas definitions as `.ghs` (shorthand text, see dev/04_shorthand.md §7) |
| `dryrun.py`, `probe_internals.py` | setup helpers (not part of the counts) |

To run:
1. Start Rhino with Nextra.
2. Install RhinoMCP temporarily, and remove it afterwards: `Yak.exe install rhinomcp`.
3. Start both servers: `python tools/nx.py run '{}' --code test/v2/start_servers.py`.
4. Run the cases: `python test/v3/bench_v3.py [01 02 …]`.
5. Build the tables: `python test/v3/gen_report3.py`.
