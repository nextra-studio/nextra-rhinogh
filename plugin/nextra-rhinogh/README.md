# NextraRhinoGH

NextraRhinoGH connects an AI assistant to the desktop application running on your computer through a local MCP server. The plugin bundles six tools and a skill with workflow guidance. It can inspect the open model, create or edit geometry and model data, run scripts, capture views, use checkpoints, and save preferences.

## Requirements and installation

Requires Rhino 8 with the Nextra-RhinoGh plug-in installed and running. The plugin launches its MCP bridge with Node.js, which must be available to the client. Local MCP tools require a supported local execution environment, such as Claude Code or Cowork.

Follow the [installation instructions](https://github.com/nextra-studio/nextra-rhinogh#readme) for application setup. Start with inspection of your open model before asking the assistant to modify it. The tools act on the model you have open and can modify local files through supported workflows and scripts.
